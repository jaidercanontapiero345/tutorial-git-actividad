# Documentación de la Actividad: Tutorial de Git

## Proceso seguido
1. **Preparación:** Se creó una cuenta en GitHub y se instaló Git en la computadora local.
2. **Repositorio:** Se creó un repositorio remoto en GitHub y se clonó en la computadora local mediante el comando `git clone`.
3. **Documentación:** Se redactaron los capítulos del tutorial basándose en el libro oficial Pro Git, exportando cada uno en un documento PDF independiente.
4. **Control de versiones:** Por cada capítulo finalizado, se repitió el ciclo de Git para subir los archivos a internet.
